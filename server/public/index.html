🔴 Lỗi kết nối 100% — Có thể do Firewall chặn

Nguyên nhân phổ biến:

  • Windows Firewall chặn port 3001 inbound
  • URL sai IP hoặc port
  • Server chưa khởi động trên máy đích

Fix: Mở port 3001 (chạy với Admin):

netsh advfirewall firewall add rule name="Server-Bench" dir=in action=allow protocol=TCP localport=3001

localhost / 127.0.0.1 dùng loopback — gói tin không rời khỏi CPU, đi thẳng vào RAM. RAM hiện đại đạt 30–50 Gbps nên tool báo con số đó — KHÔNG phải tốc độ Ethernet.

Để đo băng thông NIC thật (≤ 1 Gbps):
Cài Server Bench trên Máy B, điền URL = http://[IP Máy A]:3001/api/bench/download, rồi chạy test. Lúc đó traffic mới chạy qua cáp Ethernet và Task Manager mới thấy NIC tăng.
